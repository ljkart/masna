## What to build

A request handler that lists books from a reading list's text. It's a plain function, so no server is needed yet.

## Acceptance criteria

- [ ] `api/books.js` exports `listBooks({ text, query })`, which returns `{ status, body }`
- [ ] With no query, `status` is 200 and `body.books` holds every valid line from `text`, using `parseLine`, oldest first
- [ ] `query.author` keeps only books whose author contains that text, ignoring case
- [ ] `query.limit` caps the number of books, and must be a whole number from 1 to 100. Anything else gives `status` 400 and a short `body.error`
- [ ] `body.skipped` counts the lines that couldn't be read, not counting blank lines
- [ ] `tests/books.test.js` covers each of these
