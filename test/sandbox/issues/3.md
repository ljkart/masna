## What to build

A page where someone can read and search the reading list. It gets its data by fetching `/web/books.txt` and passing the text to `listBooks`.

## Acceptance criteria

- [ ] `web/index.html` lists each book's title, author and year, oldest first
- [ ] A search box filters by author as the person types
- [ ] When no books match, the page says so and offers a way to clear the search
- [ ] When `books.txt` can't be loaded, the page says what went wrong and offers a retry
- [ ] The page works at phone width with no sideways scrolling, and the search box can be used from the keyboard
- [ ] A test in `tests/` checks that the page's markup has the list, the search box and the two messages
